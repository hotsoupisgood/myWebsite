Ways to do NGS analysis

24 Nov 2026

There is no single NGS analysis. The question, the organism and the type of data decide the steps.

This map shows 10 workflows. Each column is a stage and each box is one option at that stage. Turn routes on with the buttons, and select a box for its details. Hover a column name for how to choose, or a dotted word for its meaning.

Show routes (any number at once)

Lines and dots take the colour of each route that is on. On a narrow screen, the map scrolls sideways.

A sequencing read is 4 lines of text with a quality score for every base

Sequencers write reads to a FASTQ file. Each read takes 4 lines. This is one short read:

@READ_0001 sample=A
GATTTGGGGTTCAAAGCAGTAT
+
IIIIIIIIIII???????55##
  1. Line 1 is the name of the read. It starts with @.
  2. Line 2 is the bases, one letter each: A, C, G or T. N marks a base the sequencer could not read.
  3. Line 3 is a + sign that separates the bases from the scores.
  4. Line 4 has one character per base. Each character is the quality score of the base above it.

Each character stands for a number. The number is the character's ASCII code minus 33. This encoding is called Phred+33. The quality score Q gives the chance that the base is wrong. A score 10 higher means 10 times fewer errors.

CharacterCalculationScoreChance the base is wrong
I73 minus 33Q401 in 10,000
?63 minus 33Q301 in 1,000
553 minus 33Q201 in 100
#35 minus 33Q2almost certainly wrong

In this read the first bases are reliable and the last bases are not. Quality usually falls towards the end of a read. Trimmers such as fastp cut read ends where the score falls below about Q20.

Every base has its own score. A run is judged by how many of its bases reach Q30. A good Illumina run has 75 to 80 or more out of every 100 bases at Q30 or above. A real FASTQ file holds millions of these 4-line blocks and is usually compressed as .fastq.gz.
